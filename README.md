# Генератор G-кода для ИПС

Готовые сборки приложения для Windows 10 и новее.

## Скачать

[**Скачать последнюю версию**](https://github.com/CompositRu/npm_tube-releases/releases/latest/download/tube_generator_for_npm.zip)

[Все релизы](https://github.com/CompositRu/npm_tube-releases/releases)

## Установка

1. Скачайте `tube_generator_for_npm.zip`.
2. Распакуйте весь архив в отдельную папку.
3. Запустите `tube_generator_for_npm.exe`.

Папка `configs/` с пресетами параметров должна находиться рядом с exe.
Устанавливать Python отдельно не требуется.

## Инструкции

В архиве находятся инструкции, которые открываются в браузере двойным щелчком:

- `Описание_параметров.html` — описание параметров приложения.
- `Пресеты_и_режимы.html` — работа с пресетами и режимами.

Для скачивания не нужен аккаунт GitHub.
